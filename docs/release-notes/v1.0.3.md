## ZenithClipper 1.0.3

### New

- **Starts with your PC.** ZenithClipper now launches in the background when you sign in and starts recording right away, so the replay is already rolling when something happens. It's on by default.
- **Startup settings.** On Windows, Settings > Replay has two switches: **Start with Windows** and **Record on startup**. Turn off either one any time. On Linux, the controls menu has a new **Startup** item with the same two options (it uses a standard login autostart entry).

### Changed

- The Windows installer no longer asks about startup. The app manages it, and uninstalling still removes it.
