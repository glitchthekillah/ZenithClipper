## ZenithClipper 1.0.8

### Fixed on Windows

- **Importing media in the editor works again.** It couldn't find its bundled ffprobe in the installed app, so every import failed with "ffprobe.exe ... cannot find the file specified". Auto captions had the same problem finding ffmpeg.

### Downloads

| File | For |
| --- | --- |
| `ZenithClipper_1.0.8_x64-setup.exe` | **Windows 10/11, recommended.** Per user install, no admin prompt. |
| `ZenithClipper_1.0.8_x64-portable.zip` | Windows, no install. Unzip and run `ZenithClipper.cmd`. |
| `ZenithClipper-1.0.8-x86_64.AppImage` | **Linux, recommended.** Recent x86_64 distributions. Needs `zenity` and `pactl` for the controls (on most desktops already). |
| `zenithclipper_1.0.8_amd64.deb` | Ubuntu, Debian, Mint: `sudo apt install ./zenithclipper_1.0.8_amd64.deb` |
| `zenithclipper-1.0.8-linux-x64.tar.gz` | Other Linux. Needs `ffmpeg`, `zenity`, `pactl` and `libmlt7`. |
| `SHA256SUMS` | Checksums for every file above. |
