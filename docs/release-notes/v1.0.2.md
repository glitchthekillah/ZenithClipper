## ZenithClipper 1.0.2

### Improved

- **Smoother editor preview on Windows.** Playback and scrubbing now decode video on your GPU (D3D11/DXVA) instead of a single CPU thread. High resolution and high frame rate clips no longer stutter. If the GPU can't decode a file, FFmpeg decodes it on the CPU as before. This only affects the editor. Background recording is unchanged.
- **The Memory tile now shows the recorder only.** It counts the recording engine and the FFmpeg it starts, and no longer picks up the editor's preview or thumbnail decoders. The label now reads "recorder only".

### New

- **Help row in Settings > Storage** with a link to the support Discord: https://discord.gg/4ju5pj5HDW
