## ZenithClipper 1.0.4

### Improved

- **Updates install themselves on every kind of copy.** "Update now" downloads the newest release, checks it against SHA256SUMS, installs it and reopens ZenithClipper. No trip to GitHub.
  - Windows installer: runs the new installer silently.
  - Windows portable: unpacks the new version over the old one and keeps your settings and clips folder.
  - Linux AppImage: swaps the file in place.
  - Linux .deb: asks for your password once, then installs the new package.
  - Linux .tar.gz: unpacks the new version over the old folder.
- Updates always jump straight to the newest version, even if you skipped a few.

### Downloads

| File | For |
| --- | --- |
| `ZenithClipper_1.0.4_x64-setup.exe` | **Windows 10/11, recommended.** Per user install, no admin prompt. |
| `ZenithClipper_1.0.4_x64-portable.zip` | Windows, no install. Unzip and run `ZenithClipper.cmd`. |
| `ZenithClipper-1.0.4-x86_64.AppImage` | **Linux, recommended.** Recent x86_64 distributions. Needs `zenity` and `pactl` for the controls (on most desktops already). |
| `zenithclipper_1.0.4_amd64.deb` | Ubuntu, Debian, Mint: `sudo apt install ./zenithclipper_1.0.4_amd64.deb` |
| `zenithclipper-1.0.4-linux-x64.tar.gz` | Other Linux. Needs `ffmpeg`, `zenity`, `pactl` and `libmlt7`. |
| `SHA256SUMS` | Checksums for every file above. |
