## ZenithClipper 1.0.6

### New on Linux

- **Choose where clips are saved.** Open the controls and pick **Clip folder**.
- **Microphone in clips.** Open the controls and pick **Microphone in clips** to mix your default microphone into every clip. It's off by default.

### Downloads

| File | For |
| --- | --- |
| `ZenithClipper_1.0.6_x64-setup.exe` | **Windows 10/11, recommended.** Per user install, no admin prompt. |
| `ZenithClipper_1.0.6_x64-portable.zip` | Windows, no install. Unzip and run `ZenithClipper.cmd`. |
| `ZenithClipper-1.0.6-x86_64.AppImage` | **Linux, recommended.** Recent x86_64 distributions. Needs `zenity` and `pactl` for the controls (on most desktops already). |
| `zenithclipper_1.0.6_amd64.deb` | Ubuntu, Debian, Mint: `sudo apt install ./zenithclipper_1.0.6_amd64.deb` |
| `zenithclipper-1.0.6-linux-x64.tar.gz` | Other Linux. Needs `ffmpeg`, `zenity`, `pactl` and `libmlt7`. |
| `SHA256SUMS` | Checksums for every file above. |
