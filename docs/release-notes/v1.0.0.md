## ZenithClipper 1.0.0

First public release. ZenithClipper keeps the last minutes of your screen in a rolling buffer and saves a clip when you press a hotkey, with a full clip editor built in.

### Downloads

| File | For |
| --- | --- |
| `ZenithClipper_1.0.0_x64-setup.exe` | **Windows 10/11, recommended.** Installs per user (no admin prompt), adds Start menu shortcuts, optional start with Windows. |
| `ZenithClipper_1.0.0_x64-portable.zip` | Windows, no install. Unzip anywhere and run `ZenithClipper.cmd`. Settings and clips stay in the folder. |
| `zenithclipper_1.0.0_amd64.deb` | Ubuntu, Debian and derivatives: `sudo apt install ./zenithclipper_1.0.0_amd64.deb` |
| `zenithclipper-1.0.0-linux-x64.tar.gz` | Other Linux distributions. Needs `ffmpeg`, `zenity`, `pactl` and `libmlt7` from your package manager. |
| `SHA256SUMS` | Checksums for every file above. |

Nothing else to install on Windows: .NET, FFmpeg and the editor's video engine are bundled.

### Highlights

- **Instant replay:** up to hours of history on disk, saved with one hotkey (Alt+C by default). Hardware encoding on NVIDIA (native capture, no CPU copies), AMD and Intel. It never silently falls back to CPU encoding.
- **Per-app audio:** choose which apps clips hear, e.g. keep Discord or Spotify out.
- **Clip editor:** timeline with drag and drop, trim, split (Ctrl+K), undo/redo, titles, captions, effects, keyframes and colour.
- **Imports:** MP4, MOV, MKV, WebM, AVI, MP3, WAV, FLAC, OGG, PNG, JPG, GIF, WebP, PSD and more.
- **Exports:** MP4 (H.264, H.265, AV1, NVENC), MOV, MKV, WebM, animated GIF, MP3, WAV, M4A and FLAC, plus Discord and YouTube presets.
- **Appearance:** pick an accent colour and background; the panel and editor update live.

### Linux status

X11 recording and the editor work, and both were tested on Linux (recording on a virtual X11 display, not a physical desktop). Wayland capture through the screen-sharing portal is included but experimental. The control panel on Linux uses simple dialogs rather than the Windows panel.
