## ZenithClipper 1.0.1

### New

- **AppImage for Linux.** One file, no install: `chmod +x ZenithClipper-1.0.1-x86_64.AppImage` and run it. The editor's video engine, effects and FFmpeg are bundled.
- **In-app updates.** Settings > Storage now has a "Check for updates" button. On the Windows installer and the AppImage it downloads the new version, checks it against SHA256SUMS and restarts into it. Portable and .deb copies open the release page.
- **Update notifications.** When a new release is out you get one notification with an "Update now" button. The check is a single small request at most once a day, and nothing runs inside the recorder.

### Fixed

- **Linux: recording stopped with "Error" after about a minute** (seen on Linux Mint). FFmpeg was being shut down when an idle engine thread exited. Capture now stays up, and if FFmpeg ever does exit unexpectedly the engine restarts it and writes the reason to `engine.log`.
- **Linux: recorded the wrong display or size.** Capture now follows `$DISPLAY` and the real screen size instead of assuming `:0` at 1920x1080.
- **Linux: no audio on some PulseAudio/PipeWire setups.** If the audio routing module can't load, ZenithClipper records the desktop output directly and says so.
- The accent colour picker no longer clips its ring, and the custom colour swatch got a cleaner look.
