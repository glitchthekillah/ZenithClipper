## ZenithClipper 1.0.7

### Fixed on Linux

- **The controls now open on KDE desktops** like Bazzite, Kubuntu and Fedora KDE, which ship without zenity. ZenithClipper uses kdialog there instead. If neither is installed, it now shows a notification saying so instead of doing nothing.

### Downloads

| File | For |
| --- | --- |
| `ZenithClipper_1.0.7_x64-setup.exe` | **Windows 10/11, recommended.** Per user install, no admin prompt. |
| `ZenithClipper_1.0.7_x64-portable.zip` | Windows, no install. Unzip and run `ZenithClipper.cmd`. |
| `ZenithClipper-1.0.7-x86_64.AppImage` | **Linux, recommended.** Recent x86_64 distributions. Needs `zenity` and `pactl` for the controls (on most desktops already). |
| `zenithclipper_1.0.7_amd64.deb` | Ubuntu, Debian, Mint: `sudo apt install ./zenithclipper_1.0.7_amd64.deb` |
| `zenithclipper-1.0.7-linux-x64.tar.gz` | Other Linux. Needs `ffmpeg`, `zenity`, `pactl` and `libmlt7`. |
| `SHA256SUMS` | Checksums for every file above. |
