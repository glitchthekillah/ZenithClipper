## ZenithClipper 1.0.5

### Fixed

- **The replay timer no longer flickers between 2:00 and 2:01.** History is stored in chunks of about a second, so it briefly ran one chunk over before trimming. The timer now stops exactly at your replay history length.
- **Clearer label under the timer.** "buffered of 2:00 history" read like a time of day. It now says "saved · keeps the last 2 minutes".
